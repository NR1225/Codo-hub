# Жылан ойыны

Canvas-та жазылған классикалық жылан: тамақ жеген сайын ұзарады және әр 5 ұпай сайын жылдамдайды.
Қабырғаға не өзіне соғылса — ойын бітеді. Рекорд браузерде сақталады.

- **Көрсеткілер / WASD** — бағыт
- **Бос орын** — пауза, ойын біткенде қайта бастау

`index.html` файлын ашыңыз немесе «Іске қосу» батырмасын басыңыз.
